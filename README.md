# ركن اليمامة لصيانة السيارات الصينية (Demo)

نسخة عرض (واجهة أمامية) لموقع الورشة المسجّلة في خرائط Google باسم **"صيانة سيارات صيني"**، واسمها على اللافتة: **مؤسسة ركن اليمامة لصيانة السيارات — ميكانيكا، كهرباء، برمجة، سمكرة** (محل رقم 5، أم الحمام الشرقي، الرياض). Vue 3 + Vite، عربي/إنجليزي.

## التشغيل
```bash
npm install
npm run dev
```
الرفع على Vercel: GitHub ثم Import (Build: `npm run build`، Output: `dist`).

## الأصول (`public/img/`)
من صور الورشة على خرائط Google: اللافتة، محرك مفكوك، شانجان أثناء الصيانة، وسيارات داخل الورشة. صورهم قليلة (حوالي 7) لذلك صمّمت باقي الموقع بأيقونات ورسومات SVG.
موقعهم الحالي aalam-elseni.com دومينه غير موجود. لا يوجد حساب سوشيال ظاهر.

## المحتوى
- الخدمات من اللافتة (ميكانيكا، كهرباء، برمجة، سمكرة) + الجيربوكس من المراجعات + فحص قبل الشراء (مقترح — تأكد).
- قائمة الماركات مقترحة (MG وشانجان وجيلي ظاهرة في صورهم ومراجعاتهم) — تأكد منها مع الورشة.
- ضمان الشهر على الجيربوكس والمهندس طارق وإبراهيم من مراجعات حقيقية.
- مفتوح 24 ساعة حسب Google.

## قبل الإطلاق الرسمي
احذف `noindex` من `index.html` وشريط "نسخة عرض" من `src/App.vue`.
